## 1. 背景与目标

### 1.1 市场背景（摘要）

- 全球下载侧由 **2D 休闲益智** 主导（份额约 40%+）。
- Puzzle 品类 H1 收入约 **$76 亿**，同比约 **+20%**。
- 头部下载对标：`Block Blast!`、Arrow 系、`Smash Fest!` 等短局强反馈产品。
- 收入榜中重度/IP（王者、Roblox、PUBG 等）不适合作为小团队首发对标。

### 1.2 产品目标

在 2–3 周内交付可试玩的全球向 MVP：

1. **获客**：玩法与竖版素材钩子适合买量/自然传播（一击连锁、清盘爽感）。
2. **留存**：前 3 分钟只靠手感；单局 3–60 秒；失败可复活。
3. **变现**：广告位齐全（Banner / 插屏 / 激励），MVP 可用 Mock，节奏可验收。

### 1.3 非目标（明确不做）

- Match-3 硬刚 `Royal Match`（关卡产能与买量军备）
- SLG / 二游 / 开放世界 / 大逃杀
- 社交、赛季、公会、复杂成长树、Battle Pass
- 纯无脑超休闲（无局内目标、无失败态）
- 首发全语言、重 LiveOps

## 2. 产品定义

### 2.1 一句话

> 3–60 秒一局、一指操作、破坏/消除反馈拉满；前 3 分钟只靠手感留人，广告变现，后续再加轻关卡与主题皮肤。

### 2.2 品类定位

| 维度 | 定义 |
| --- | --- |
| 品类 | 物理反馈型 2D 益智（Hybrid Casual） |
| 核心体验 | 「可预判的轻物理连锁 + 网格/结构约束」 |
| 对标手感 | `Block Blast!`、`Smash Fest!` |
| 对标规则简洁 | `Arrow Puzzle` |
| 对标包装 | `Meowdoku!`（主题皮肤抬 CTR，不抄玩法） |
| 差异化 | 不做纯箭头换皮；素材可拍「一击倒塔」，玩法用 Unity 2D Physics 落地 |

### 2.3 目标用户

- 全球休闲玩家，碎片时间游玩（通勤、等待）。
- 接受广告变现；对短局、强反馈、低认知门槛敏感。
- 不依赖重度养成或叙事。

## 3. 核心玩法需求

### 3.1 核心循环

```text
进入局 → 瞄准/落子（一指）→ 触发消除或物理坍塌
      → 连击/评分反馈 → 继续或失败
      → 复活（RV）或结束 → 局间插屏 → 下一局
```

### 3.2 模式（MVP）

| 模式 | 优先级 | 说明 |
| --- | --- | --- |
| 无限分（Endless） | P0 | 默认可连续开局；分数累计；失败结束本局 |
| 每日挑战（Daily） | P0 | 日期种子固定一关；本地最高分；每日刷新 |
| 冒险关卡（30 关） | P2 | MVP 不做；后续扩展 |

### 3.3 操作与反馈（P0）

| ID | 需求 | 验收 |
| --- | --- | --- |
| G-01 | 一指操作（拖放或 tap 瞄准，二选一锁定实现） | 无需双指/复杂手势 |
| G-02 | 每次有效操作有明确视觉反馈（消除/击倒/连锁） | 录像可见 |
| G-03 | 连击或 Perfect 类文案至少一种 | 英文文案 |
| G-04 | 粒子或轻震动至少一种 | 可关震动 |
| G-05 | 单局目标时长 3–60 秒可自然结束 | 抽样 10 局统计 |
| G-06 | 失败态清晰：失败面板 + 复活入口 | UI 可用 |

### 3.4 难度与手感原则

- 前 15 秒必须出现一次「爽反馈」（消除或坍塌）。
- 难度靠布局/弹药或可放置空间约束，不做隐藏数值压玩家。
- 避免 Arrow 赛道纯换皮标题与素材（商店同质化风险）。

## 4. 系统需求

### 4.1 流程与场景

| 场景 | 职责 |
| --- | --- |
| Boot | 初始化 Ads/Analytics（可 Mock）、进入 Main |
| Main | Play / Daily Challenge / Settings |
| Game | Board + HUD + 失败/复活面板 |

### 4.2 元系统（MVP）

| ID | 需求 | 优先级 |
| --- | --- | --- |
| M-01 | 本地最高分（Endless） | P0 |
| M-02 | 每日挑战：按 UTC 或本地日期生成种子关 | P0 |
| M-03 | Settings：音效/震动开关 | P0 |
| M-04 | 主题皮肤 2 套可切换 | P1（可延后） |
| M-05 | 账号/云存档/排行榜联网 | P2（不做） |

### 4.3 本地化

| ID | 需求 | 优先级 |
| --- | --- | --- |
| L-01 | 键值本地化框架（Loc） | P0 |
| L-02 | 全量英文文案 | P0 |
| L-03 | 其他语言资源 | P2 |

### 4.4 广告与变现

| 广告位 | 触发 | MVP |
| --- | --- | --- |
| Banner | 对局 HUD 底部常驻 | 接口 + Mock |
| Interstitial | 局间（自然断点） | 接口 + Mock；可配置冷却 |
| Rewarded | 失败复活（建议每局限 1 次） | 接口 + Mock |

| ID | 需求 | 优先级 |
| --- | --- | --- |
| A-01 | `IAdService`：Banner / Interstitial / Rewarded | P0 |
| A-02 | `MockAdService` 可完成节奏验收 | P0 |
| A-03 | 真实 SDK（Unity Ads 或 LevelPlay 择一） | P1 |
| A-04 | 去广告 IAP | P1 |
| A-05 | Battle Pass / 强付费商城 | 不做 |

原则（对齐 Block Blast 级克制）：

- 不对中盘强制打断操作。
- 激励视频用于自愿复活，不硬锁进度墙。
- FTUE 前若干局可延迟插屏（建议前 3 局或前 90 秒无插屏）。

### 4.5 数据与分析（事件表草案）

| 事件 | 参数（示例） | 优先级 |
| --- | --- | --- |
| `app_open` | version | P1 |
| `ftue_complete` | duration_sec | P1 |
| `run_start` | mode=endless\|daily | P1 |
| `run_end` | score, duration, reason=fail\|quit | P1 |
| `revive_offer` | — | P1 |
| `revive_complete` | watched=bool | P1 |
| `ad_impression` | type=banner\|interstitial\|rewarded | P1 |
| `daily_complete` | score | P1 |

MVP 可先打本地日志；真 Analytics 后接。

## 5. 非功能需求

| ID | 类别 | 要求 |
| --- | --- | --- |
| N-01 | 性能 | 主流中端 Android / 近 3 年 iPhone，对局稳定 ≥ 30 FPS |
| N-02 | 包体 | MVP 目标安装包尽量 < 80MB（含压缩纹理） |
| N-03 | 离线 | 核心玩法可离线；广告失败时不阻断开局 |
| N-04 | 合规 | 素材不夸大未实现玩法；广告频率可配置 |
| N-05 | 平台 | 优先可出 iOS + Android 试玩包；商店提审细节 P1 |

## 6. MVP 范围与验收

### 6.1 必须（P0）

| ID | 标准 |
| --- | --- |
| A1 | FTUE ≤ 15 秒：首次操作即有消除/破坏反馈 |
| A2 | 单局 3–60 秒可结束；失败有复活 RV 入口（可 Mock） |
| A3 | 无限分模式可连续游玩；局间插屏位预留 |
| A4 | 连击/Perfect 文案 + 粒子或震动至少一种 |
| A5 | 每日挑战：固定种子关卡 + 本地最高分 |
| A6 | 英文 UI；本地化键值框架就绪 |
| A7 | Ads 接口抽象 + Mock 可切换 |

### 6.2 可延后（P1）

| ID | 标准 |
| --- | --- |
| B1 | 主题皮肤换装（2 套） |
| B2 | 真实广告 SDK + Analytics 事件上报 |
| B3 | 去广告 IAP |
| B4 | 竖版买量素材 3 条（一击倒塔 / ASMR 碎裂 / 近失弹） |

### 6.3 成功标准（立项对齐）

- 能说清：做什么、不做什么、为何能全球获客。
- 2–3 周内可用现有 Unity 版本打出试玩包。
- 变现路径以广告为主，不依赖首月重付费。

## 8. 风险与规避

| 风险 | 规避 |
| --- | --- |
| Arrow/Block 赛道拥挤 | 视觉与素材强调物理连锁，避免「箭头格子」纯换皮命名 |
| 素材疲劳 | 优先测击倒/ASMR/近失弹钩子；每周迭代创意假设 |
| 商店下架/合规波动 | 控制广告频率；素材不误导；预留 iOS 优先路径 |
| 物理手感难打磨 | W1 尽早可玩；把反馈（音画触）列为与规则同等优先级 |

## 10. 附录：对标速查

| 产品 | 循环 | 变现要点 | 立项启示 |
| --- | --- | --- | --- |
| Block Blast! | 三块入 8×8 → 满行/列消 | 纯 IAA，复活 RV 克制 | 手感与广告克制标杆；勿硬抄烧 UA |
| Arrow 系 | 点箭头滑出清盘 | 关间插屏 + 提示/续命 | 规则简单但同质化最高 |
| Smash Fest! | 限弹击倒连锁坍塌 | Hybrid，插屏延后 | 物理爽感差异大；注意合规 |
| 主题 Sort/数独 | 经典规则 + 皮肤 | IAA + 皮肤软 IAP | 学包装，不单靠主题建壁垒 |
